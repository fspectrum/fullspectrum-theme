# **FullSpectrum Theme for VS Code**

## **Descripción**

Extensión para Visual Studio Code que incluye dos temas personalizados (oscuro y claro) basados en la identidad visual de la fábrica de software **FullSpectrum Tech**. Diseñado para facilitar sesiones de desarrollo largas con una estética coherente y cómoda, ideal para entornos con Spring Boot, Angular, Java y Markdown.

## **Temas incluidos**
- 🎨 **FullSpectrum Dark** — Colores suaves con enfoque en el púrpura como color principal, reduciendo la fatiga visual.
- 💡 **FullSpectrum Light** — Alternativa clara con alto contraste controlado, ideal para ambientes muy iluminados.

## **Instalación**

### Desde el Marketplace

> [¡Instalar desde Visual Studio Marketplace!](https://marketplace.visualstudio.com/items?itemName=fullspectrum-dev.fullspectrum-theme)

### Desde VS Code

```bash
# Instalación rápida desde terminal VS Code
code --install-extension fullspectrum-dev.fullspectrum-theme
```

### Desde el archivo VSIX

```bash
vsce package
code --install-extension fullspectrum-theme-1.0.0.vsix
```
