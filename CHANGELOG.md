# Change Log

All notable changes to the "fullspectrum-theme" extension will be documented in this file.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.

## [2.1.0] - 2025-05-01
### Added
- Introduced FullSpectrum Angular 17 Light and Dark themes.
- Added Oh My Posh themes: `angular-light.omp.json` and `angular-dark.omp.json`.

### Changed
- Updated `package.json` to version 2.1.0.

## [2.0.0] - 2025-05-01
### Added
- Introduced a new light theme: FullSpectrum Spring Boot Light.
- Introduced a new dark theme: FullSpectrum Spring Boot Dark.
- Added a new Oh My Posh theme: `springboot-light.omp.json`.
- Enhanced FullSpectrum Dark and Light themes with additional tab and panel styling.

### Changed
- Updated `package.json` to version 2.0.0 and included new Spring Boot themes in the theme list.

## [1.0.2] - 2025-05-01
### Added
- Added FullSpectrum theme package version 1.0.2.

## [1.0.1] - 2025-05-01
### Changed
- Updated version to 1.0.2 in `package.json`.

## [1.0.0] - 2025-05-01
### Added
- Created the FullSpectrum theme in light and dark variants.
